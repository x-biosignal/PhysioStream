# Map between synchronized signal and video time

Map between synchronized signal and video time

## Usage

``` r
videoSyncTime(sync, signal_time)

signalSyncTime(sync, video_time)
```

## Arguments

- sync:

  A validated `VideoSync`.

- signal_time:

  Finite signal-domain times.

- video_time:

  Finite media times.

## Value

A numeric vector preserving names.
